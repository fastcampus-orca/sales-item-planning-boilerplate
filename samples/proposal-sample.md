# 판매 아이템 기획서

> 양식에 맞춰 작성된 샘플입니다. 소재와 수치·출처는 설명용 가상 값입니다.

## 1. 개요
선정 아이템 연말정산 연계 가계부 템플릿 / 고객 20~30대 직장인 / 한 줄 컨셉 연말정산 준비까지 이어지는 가계부 / 소싱 방식 직접 제작

## 2. 시장분석
12~1월 검색 증가(E1). 상위 상품 수는 중간 수준(E2). 수수료를 뺀 예상 마진율 76%(E3, 결제 수수료는 추정).

## 3. 아이템 선정 근거
총점 8점(마진 3·경쟁 2·트렌드 3)으로 후보 중 1위. 대안은 7점인 자격증 공부 플래너.

## 4. 실행 로드맵
| 단계 | 기간 | 할 일 |
| --- | --- | --- |
| 제작 | 1~2주 | 템플릿과 사용 설명서 제작 |
| 등록 | 3주 | 판매 페이지 등록 |
| 점검 | 4~8주 | 주간 판매 수와 문의 기록 |

## 5. 예산
| 항목 | 금액(원) | 계산 근거 |
| --- | --- | --- |
| 디자인 소스 구매 | 50,000 | 소스 1종 (추정) |
| 광고 테스트 | 100,000 | 2주 × 50,000 |

| 리스크 | 대응 방법 |
| --- | --- |
